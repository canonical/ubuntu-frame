# Snap553 (Mir 2.31.0)

## 7 October 2026

These release notes cover new features and changes in Ubuntu Frame version `snap553-mir2-31-0`.

All Ubuntu Frame releases are designated as long-term support release within a track.
This means it will continue to receive security updates and critical bug fixes for five years.
With an Ubuntu Pro subscription, access to ESM (Expanded Security Maintenance) updates will be available for ten years.

## Requirements and compatibility

For development and testing purposes, a machine or VM with a minimum of 1GB RAM is required.
In production, at least 2GB RAM is recommended.

## What’s new in Ubuntu Frame version<br />`snap553-mir2-31-0`

### HDMI-CEC display control

Displays such as general-purpose TVs often don't react to the common DPMS signals the display hardware sends normally.
With the {ref}`global-cec-control` option enabled, Ubuntu Frame will manage the power and input routing of connected HDMI-CEC compatible devices.
This requires a CEC adapter compatible with the [`libcec` - the CEC Adapter communication library](https://libcec.pulse-eight.com).
On startup and display configuration changes, displays will be turned on and their output routed to Frame,
or put to standby, aligned with the current display configuration.
