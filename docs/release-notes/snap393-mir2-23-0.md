# Snap 393 (Mir 2.23.0)

These release notes cover notable changes for snap source definition commit count 393.

## What’s new

- Updated to [Mir 2.23.0](https://github.com/canonical/mir/releases/v2.23.0), including changes from [Mir 2.22.0](https://github.com/canonical/mir/releases/v2.22.0).
- Added property-based display configuration for flexible output management.
- Added custom client placement for multi-output configurations with support for exact positioning ([#218](https://github.com/canonical/ubuntu-frame/pull/218)).
- Added atomic-kms platform support for improved graphics handling ([#211](https://github.com/canonical/ubuntu-frame/pull/211)).
- Added OWASP-compliant security event logging ([#269](https://github.com/canonical/ubuntu-frame/pull/269), [#271](https://github.com/canonical/ubuntu-frame/pull/271)).
- Migrated the documentation to Read the Docs with an improved structure ([#228](https://github.com/canonical/ubuntu-frame/pull/228), [#231](https://github.com/canonical/ubuntu-frame/pull/231), [#233](https://github.com/canonical/ubuntu-frame/pull/233)).
- Added the ability to disable Virtual Terminal switching for enhanced security.
