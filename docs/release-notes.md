# Release notes

Ubuntu frame is released on https://snapcraft.io/ubuntu-frame.

## 24/stable 457-mir2.26.0

- Updated to [Mir 2.26.0](https://github.com/canonical/mir/releases/v2.26.0)
- Documentation migrated to ubuntu.com/frame/docs with improved structure ([#305](https://github.com/canonical/ubuntu-frame/pull/305))

## 24/stable 406-mir2.25.2

- Updated to [Mir 2.25.2](https://github.com/canonical/mir/releases/v2.25.2) with new accessibility and window management features:
  - Improved cursor scale animation
  - LocatePointer accessibility feature for finding the cursor

## 24/stable 393-mir2.23.0

- Updated to [Mir 2.23.0](https://github.com/canonical/mir/releases/v2.23.0) through [Mir 2.22.0](https://github.com/canonical/mir/releases/v2.22.0)
  - Property-based display configuration for flexible output management
- Custom client placement for multi-output configurations with support for exact positioning ([#218](https://github.com/canonical/ubuntu-frame/pull/218)
- Atomic-kms platform support for improved graphics handling ([#211](https://github.com/canonical/ubuntu-frame/pull/211))
- OWASP-compliant security event logging ([#269](https://github.com/canonical/ubuntu-frame/pull/269), [#271](https://github.com/canonical/ubuntu-frame/pull/271))
- Documentation migrated to Read The Docs with improved structure ([#228](https://github.com/canonical/ubuntu-frame/pull/228), [#231](https://github.com/canonical/ubuntu-frame/pull/231), [#233](https://github.com/canonical/ubuntu-frame/pull/233))
- Ability to disable Virtual Terminal switching for enhanced security

## 24/stable 211-mir2.20.1

- Users can now control the visibility of app icons in different environments
  in the launcher.
